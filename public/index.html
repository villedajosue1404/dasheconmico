🤖 Bot de Telegram
Token del bot y Chat ID — se guardan en el servidor, no en tu navegador
  1. Abrí Telegram → buscá @BotFather
  2. Enviá /newbot → elegí nombre y username (debe terminar en bot)
  3. BotFather te dará el token. Copialo abajo.
  4. Agregá el bot a tu canal como administrador
  5. Para el Chat ID: enviá un mensaje al canal, luego abrí https://api.telegram.org/bot[TOKEN]/getUpdates y buscá chat.id
✅ Se guarda en la base de datos del servidor. Solo tenés que configurarlo una vez. Todos los que accedan a la app lo usarán automáticamente.
2
📘 Facebook Page
Page Access Token y Page ID
  1. Andá a developers.facebook.com → Crear app → Empresa
  2. En Graph API Explorer, agregá permisos: pages_manage_posts, pages_read_engagement
  3. Generá el Access Token y copiá el Page ID de tu página
