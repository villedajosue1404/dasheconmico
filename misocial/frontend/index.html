URL de PocketBase
📖 Cómo desplegar PocketBase en Railway (gratis):
1. Creá cuenta en railway.app
2. Hacé clic en "New Project" → "Deploy from GitHub repo"
3. Subí la carpeta railway/ que viene en el ZIP a un repo de GitHub
4. Railway te dará una URL como https://tu-app.railway.app
5. Pegá esa URL arriba y hacé clic en "Conectar"
6. ¡Listo! Todos los datos se guardan remotamente y cualquiera con la URL puede acceder.
1
🤖 Telegram — cómo crear tu Bot
El token se guarda por negocio, no globalmente
  1. Abrí Telegram → buscá @BotFather
  2. Enviá /newbot y seguí las instrucciones
  3. BotFather te da un token como 123456:ABCdef...
  4. Agregá el bot a tu canal como administrador
  5. Para el Chat ID: mandá un msg al canal y abrí https://api.telegram.org/bot<TOKEN>/getUpdates
  6. Guardá el token y Chat ID en la configuración de cada negocio
2
📘 Facebook — cómo obtener el token
  1. Andá a developers.facebook.com → Crear app
  2. Agregá el producto "Graph API"
  3. En Graph API Explorer, pedí permisos: pages_manage_posts
  4. Generá el Page Access Token y copiá el Page ID
  5. Guardá ambos en la configuración del negocio correspondiente
Nota: Los tokens de prueba expiran en 1 hora. Para producción, generá un token de larga duración.
